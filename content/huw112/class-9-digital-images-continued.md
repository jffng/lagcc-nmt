### Review

Pixels, RGB, raster vs. vector, and the Figma tools you've used: text, frames, alignment, scaling, crop, fill, flattening, shapes + unions.

### Demo

**Core**
- **Text over images:** put a dark gradient or a semi-transparent box behind captions so they read on any photo
- **Panels**
	- One photo in a rectangle → set the shape's fill to the image
	- Several layers (drawing + bubble) → use a frame; it hides anything outside its edges
	- Odd shape → mask
- **Even gutters** (the gaps between panels): select panels → Distribute. For more control, Shift + A (auto layout) and set the gap
- **Speech bubbles:** ellipse + pen-tool tail → Union. Put the text in auto layout so the bubble grows with your words
- **Tap-through preview:** connect your frames in Prototype mode, then open it in the Figma mobile app to check it at phone size

**If time**
- **Close-up vs. wide:** crop the same photo tight and wide
- **Drawings on paper:** photograph it → set the layer to Multiply → the white paper disappears, the lines stay
- **Consistent look:** use the same adjustment settings on every photo
