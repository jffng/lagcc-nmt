### Demo: pen tool

A pen path is vector (SVG): it stays sharp at any size.

- **Basics**
	- Click = straight point, click + drag = curve
	- Click the first point to close the shape
	- Double-click a point to edit it later
- **Bubble tails + thought bubbles:** draw the tail with the pen → select it and the ellipse → Union
- **Odd-shaped panels:** draw the panel with the pen → place your image inside it → Use as mask
