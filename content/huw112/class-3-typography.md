## Class 3: Typography

### Agenda

- **Typography lecture**
- **Break**
- **Well done / not well done activity**

### Lecture

Today we're covering the basics of typography — what it is, how it's used today,
and some hands-on practice with Figma's typography tools.

We'll go through the history of typography using
[this Figma presentation](https://www.figma.com/deck/fNt0L7rN7r9o8yrREW6J1o),
tracing how text has evolved: from early pictographs (picture-based symbols), to
movable type (Gutenberg's printing press, which made mass-produced text possible),
to ASCII (the standard system computers first used to represent text and
characters), to where we are today — emojis, memes, and captions layered over
video.

### Activity: Well Done / Not Well Done

Find three examples of text you think is well done. It can be real-life (a
poster, sign, or advertisement) or digital (a music video, website, video
captions, or game UI).

Then find three examples of text in the wild you think is *not* well done.

For each of your six examples, explain:
- What it is
- What you like or dislike about it
- What stands out to you about the text specifically — if you're stuck, ask
  yourself:
  - *How close together are the letters?*
  - *Does the text look thick/bold or thin/light?*
  - *Is it easy or hard to read at a glance?*
  - *Does it have little "feet" on the letters, or not?*

We'll come back to these six examples in a future class and connect what you
noticed to the actual vocabulary designers use for it (kerning, weight, line
height, serifs).

**Instructions:**
1. Create a new Figma Design file.
2. Create six frames, one for each example.
3. In each frame, add a photo or screenshot of the example.
4. Add your written explanation in the same frame.
