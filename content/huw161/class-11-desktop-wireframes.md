### Demo: desktop

- **Button**
	- Type text, **Shift+A** (auto layout)
	- Add padding + fill
	- Change the text: the button grows
- **Component**
	- Select button, **Cmd+Opt+K** (Ctrl+Alt+K on Windows)
	- Drag out 3 copies, change one label
	- Edit the main component: all copies update
- **Card**
	- Image box + heading + text + button
	- Select all, **Shift+A**: vertical, set gap + padding
	- Make it a component
	- Duplicate 3×, select, **Shift+A**: a row of cards
